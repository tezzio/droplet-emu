# Contributing

Droplet is an independent project built on [eden-nx2](https://git.eden-emu.dev/Takoroka/eden-nx2)
and [Eden](https://git.eden-emu.dev/eden-emu/eden); [CREDITS.md](CREDITS.md) lists everyone whose
work it uses. Its only official place is its GitLab project, <https://gitlab.com/seighttt/droplet>.
It has no official Discord server or other community chat.

- **Problems with Droplet** go to its GitLab project, not to Eden, eden-nx2, yuzu or any other
  project Droplet builds on. They don't support Droplet.
- **Changes must keep the [legal notice](README.md#legal-notice) true:** nothing that reads or
  uses keys or opens encrypted formats, and no Nintendo material.
- **Style:** new code follows the style of the code around it. See
  [docs/policies/Coding.md](docs/policies/Coding.md) and [docs/Development.md](docs/Development.md).
- **License:** Droplet is under the GNU General Public License, version 3 or later
  ([LICENSE.txt](LICENSE.txt)), and so is anything contributed to it.

The pages in [docs](docs/README.md) come from Eden and describe how Eden's developers work; where
they differ from this page, this page applies to Droplet.
